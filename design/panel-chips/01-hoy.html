What is wrong

  1. Two states, one glyph. Idle, Not started and Loading… all draw ○: only the word tells them apart.
  2. Different sizes. ◔ ▲ ✖ ◌ are not drawn at the same size or weight; it depends on the font of each system (you saw it in your screenshots).
  3. The memory chip has no icon while the context chip does.
  4. The rest of the page uses drawn SVG icons (tabs, trees, CI): the chips are the only place with text characters.
