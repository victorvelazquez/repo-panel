Notes

  1. Not only colour: Idle (check), Not started (dashed ring), Starting (open ring), Working (disc), Compacting (corners), Asking (bubble), Unknown (question mark); the context goes arc, triangle with !, circle with x.
  2. Motion: only the three states that already pulse (Starting, Working, Compacting); it stops under reduced motion.
  3. Memory gets the icon it did not have: a cylinder, plain when ready, crossed when offline, with a badge on error, with a bar when disabled.
  4. Icons are decorative (aria-hidden): the word is still in the chip and the tooltip does not change.
