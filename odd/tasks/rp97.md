# RP97: el id de sesión de pi, único por repositorio
Ficha de la fila RP97 de `docs/ROADMAP.md`. El id sale de `sessionIdFor` en `server/rpchost.js` (`--session-id` al arrancar `pi --mode rpc`).
Nació al repasar los hallazgos abiertos de la serie RPC (`odd/tasks/rpc.md`).

## Specs
- **S1. Origen.** «resolvamos la posible colisión del id de sesión panel-<slug>.»
- **S2. Qué cambia.** El id de una sesión NUEVA es `panel-<slug>-<id corto del repo>`: el `<slug>` es la última carpeta de la ruta, como hoy, y el id corto son los primeros 8 caracteres alfanuméricos del id del repo (el hash de su ruta), así que dos repos con la misma carpeta final ya no comparten id. Sigue cumpliendo `SESSION_ID` (hasta 80 caracteres).
- **S3. Lo que no cambia.** Un id adoptado (`config.json` `sessions`) gana siempre: ningún repo que ya arrancó una sesión cambia de id ni pierde su historial. Sin carpeta en la ruta, el id sigue siendo `panel-<id del repo>`.
